## 1 交互目标和全局约定

需求对应：SCOPE-01–04, DATA-01–04, NFR-01–04。

### IXD-01 核心交互原则

用户始终能回答：正在编辑哪个项目、哪个环境、哪个流程；本次会操作哪些服务器、按什么顺序；哪些命令会获得额外权限；现在停在哪个任务；失败后还有哪些操作发生。新增服务器和切换构建工具均通过配置完成，不出现必选“语言类型”。Git 拉取、构建、重启和检查在界面中均表现为命令步骤或模板名称，不出现独立 CI/CD 连接模式。

### IXD-02 页面与导航

一级导航为项目与流程、服务器、执行记录、流程模板、配置中心。默认进入上次项目及流程；对象已删除时回到项目列表，不自动进入其他项目运行。项目二级页为执行流程、目标服务器、变量与环境、项目设置。运行期间允许离开当前页，顶部保留活跃运行状态及返回入口，不能因切页取消任务。P0 不提供没有实现的终端、监控图或跳板机可用按钮（原 Demo 中的资源指标、拓扑图、终端、跳板机字段在 P0 中去掉）。

### IXD-03 保存、焦点与弹窗

配置采用显式保存，未保存时标题边显示“未保存”。切换项目、流程、环境或离开页面且存在草稿时，弹窗提供“保存并继续”“放弃更改”“取消”；校验失败保留弹窗上下文并定位错误，取消留在原页。模态框打开时焦点进入首个可操作字段，关闭后回到触发控件；Tab 不跳到遮罩后。普通配置弹窗 Esc 等同取消并检查脏内容；信任、发布确认、密码和取消运行弹窗不允许点击遮罩误关闭。Ctrl+S 保存当前配置。

### IXD-04 控件和反馈

页签用于视图切换；环境和流程用选择器；开关或复选框用于启用、保护环境；数字字段用步进输入；移动、复制、删除、浏览路径、显示密码、跟随日志使用标准图标并提供悬浮提示与无障碍名称。提交命令使用明确动词。网络动作一开始显示忙碌状态并防重复点击；失败留在原上下文，不清空已填写内容。状态用图标加文字，不单凭颜色。

### IXD-05 布局建议

桌面基准 1440×900，最低目标 1280×720；侧栏建议 200 px，可收窄为图标栏，顶部上下文区约 56 px。流程列表与参数区约 44:56 分配，底部日志区可调高度，最小约 180 px。空间不足时参数区转抽屉而不是挤压命令输入框；长命令横向滚动或主动换行，操作按钮固定可见。125% 缩放下不得重叠。首版不承诺移动端执行功能。

## 3 项目与流程编辑

需求对应：PRJ-01–03, STEP-01–06, RUN-01。

### IXD-06 P01 项目列表

列表列出名称、默认环境、流程数、当前环境绑定目标数和最近运行结果；最近结果必须带时间，不暗示当前服务器健康。搜索匹配名称及说明，空结果保留搜索条件和清除入口。首次空状态只展示“尚无项目”及新建按钮，不塞入自动执行示例。删除确认显示项目名称、流程数量和绑定目标数量，明确只删除本地配置，不删除服务器目录或服务；活跃运行时禁用并说明原因。

### IXD-07 项目创建与复制

创建弹窗包含名称（必填 1–64 字符）、说明、根目录（可空）、默认环境、初始模板。默认模板为空白流程；保存后创建项目和首个流程，进入 P02。不存在根目录提示路径问题；纯远端项目可留空。重名错误显示在名称下，不仅顶部提示。复制项目默认新名称为空待填写，复制流程和变量但不复制目标绑定或凭据，避免副本意外指向生产。

### IXD-08 P02 流程管理

流程选择器旁提供新建、重命名、复制、删除菜单。新增空流程后选中；复制保留步骤配置但生成新 ID。删除展示流程名及步骤数；删除最后一个流程时必须先创建替代流程，不能让项目进入不可解释状态。运行中的配置允许编辑并显示“更改将在下次运行生效”，运行详情始终显示冻结快照。

**【v0.2】** 流程级设置区包含两项：

- **执行顺序**：分段选择“步骤优先”（默认）/“服务器优先”。旁边的说明图标展开一段示例：两台服务器、构建/上传/重启三步时两种顺序的实际任务序列。
- **失败策略**：失败停止（默认）/ 失败继续 / 跳过该服务器。“跳过该服务器”在步骤优先时禁用并提示“仅服务器优先可用”；从服务器优先切回步骤优先时，若流程或任一步骤正在使用该策略，弹窗列出受影响的步骤并要求改为其他策略后才能保存。

### IXD-09 步骤列表与动作

每行固定显示序号、类型图标、名称、启用开关；选择行只更新参数区，不触发执行。图标动作包含上移、下移、复制、删除；首行上移和末行下移不可用，附原因。复制插入原步骤之后并选中新步骤；删除确认后选中下一项，没有下一项则选中上一项；没有步骤时清空参数区。禁用步骤用“已禁用”文字标识且保留配置，预览中列为不执行而非失败。

### IXD-10 步骤类型与参数

“添加步骤”菜单仅包含本地命令、上传文件、远程命令、人工确认。已创建步骤不直接切换类型，以免静默丢失不兼容字段，需新增后替换。公共字段名称、启用、超时、失败策略置于稳定位置；人工确认隐藏超时和失败策略。远程检查可通过模板添加，但参数面板仍为远程命令。

| 类型 | 可见字段 | 默认值、行为和校验 |
|---|---|---|
| 本地命令 | 命令、目录、Shell、必要时 WSL 发行版、**【v0.2】输出编码** | 命令为空不可运行；目录默认项目根；Shell 选项为 PowerShell / cmd / WSL，不可用时定位字段。目录浏览器选择本地目录，WSL 目录不使用 Windows 文件选择结果冒充。输出编码默认“自动”，可选 UTF-8 / GBK，旁边提示“出现乱码时可手动指定”。 |
| 上传文件 | 源类型、源路径、远端目标、冲突策略 | 源类型默认文件；冲突默认报错。文件选择与目录选择匹配源类型。输入目标必须完整且绝对；产物暂不存在显示待执行时检查，不预先阻断构建。 |
| 远程命令 | **【v0.2】** 写法（脚本 / 程序及参数）、命令或可执行路径与参数列表、远端目录、提权策略、必要时提权目标用户 | 写法默认脚本；程序写法的可执行路径必须为绝对路径，参数逐行填写。切换写法不自动转换内容，两种草稿各自保留，保存时只保存当前写法并先提示。目录可空；提权默认继承服务器。脚本写法加 sudo 时提示“需要服务器授权 Shell”。显示每台目标的生效策略差异，不出现“所有服务器都免密”的笼统标记。 |
| 人工确认 | 名称、确认提示 | 显示在流程中的实际位置；提示不能为空。没有服务器密码或授权配置。 |

### IXD-11 参数编辑与变量插入

命令输入使用多行代码输入框；粘贴和换行不触发执行。字段旁变量菜单按项目、当前环境、内建变量分组，选择后插入模板表达式到光标位置；敏感变量只显示名称。服务器变量在本地命令上下文中不可插入，手工输入则预检报错。参数编辑只改变草稿；保存后清除脏标记。命令预览提供目标选择器，明显区分原始模板与解析结果。

## 4 目标、变量和环境

需求对应：DATA-03, VAR-01–03, PRJ-01, RUN-01–03。

### IXD-12 P03 目标绑定

顶部显示当前环境和“已选择 N 台”。列表列包含复选框、服务器名、地址、账号、标签、最近连接测试及时间；只列该环境的服务器。保存前勾选属于草稿；切环境触发脏检查。表头全选仅影响当前筛选可见项，筛选隐藏已选项仍计数并可通过“仅已选”查看。新增服务器不会自动勾选。连接测试失败只是历史信息，不禁止绑定，但发布预览明确显示最近测试结果。**【v0.2】** 列表顺序即服务器执行次序，可拖动或用上移/下移调整，保存后生效。

### IXD-13 P04 变量编辑

表格列为变量名、项目默认值、当前环境覆盖、生效值、来源、敏感标志和操作。全局继承项可见但不可在项目页直接修改全局默认，可在项目设置覆盖。增加一行后名称获得焦点；重复名或非法字符在本行提示。环境覆盖具有“未设置”和“已设置”两个状态，空文本不能自动视为未设置；删除覆盖动作恢复继承，不删除全局或项目变量。生效值随草稿即时计算，但运行使用保存后的快照。**【v0.2】** 敏感变量的值保存到 Windows 凭据管理器，来源列显示“凭据管理器”或“环境变量 NAME”；取消敏感标记需确认（值将写回配置）；导入后缺失值时显示“需填写”。

### IXD-14 P05 项目设置与环境管理

项目设置保存名称、说明、根目录、默认环境；改变默认环境不迁移目标绑定。配置中心维护环境名称和保护开关；production 只是预置名称，保护语义由开关决定。环境被引用时删除按钮触发引用清单而不是执行删除。环境改名保留 ID 与绑定，保护环境确认时使用改名后的名称。环境保护开关变更需单独确认，不在运行快照中追溯生效。

## 5 服务器管理、测试与信任

需求对应：SRV-01–05, SEC-01, SEC-03, DATA-03。

### IXD-15 P06 列表和筛选

列表默认按名称排序，支持搜索名称/地址/标签，环境筛选和最近测试状态筛选。状态用“未测试”“测试中”“认证失败”等具体文字，不将历史失败写成实时离线。每行提供编辑、测试、删除；勾选后批量测试可用，批量按钮显示选中数。新建服务器保存成功后定位新行并标记未测试，不自动连接。

### IXD-16 D01 服务器表单

基本区：名称、地址、端口 22、用户 deploy、环境；认证区：方式及条件字段；提权区：默认不提权、sudo 免交互、sudo 运行时密码，以及目标用户；**【v0.2】兼容性区：“允许旧算法（ssh-rsa / SHA-1）”开关，默认关闭，附说明“仅用于无法升级的旧服务器，安全性较低”**；其他区：标签、备注、连接超时 10 秒。点击保存统一校验并聚焦第一个问题，全部错误同时标出，避免逐个提交猜测。取消关闭，编辑已有记录时不会因取消而改变已保存内容。

### IXD-17 认证条件字段

私钥方式显示文件路径和浏览图标，不要求上传私钥正文；**【v0.2】文件选择器同时接受 OpenSSH 私钥和 `.ppk` 文件，选择后在字段下显示识别出的格式（如“OpenSSH · 已加密”“PuTTY v3”）或“无法识别的格式”**。Agent 方式隐藏密码和路径，并提示使用的是 Windows OpenSSH Agent 还是 Pageant；运行时密码方式不显示永久密码输入框；环境变量方式只填写变量名，并提示当前是否存在但不显示值，同时提示“修改环境变量后需重启应用”。切换方式时保留当前弹窗的非敏感草稿，保存仅持久化选中方式的引用字段；输入过的凭据不得在切换中保留为普通文本。

### IXD-18 单个和批量测试

点击测试立即显示旋转状态、开始时间并禁用本行重复测试，其他行仍可操作；批测按队列逐一执行，显示已完成/总数和取消入口。测试需密码或首次信任时出现独立待办；取消单个认证使该测试取消，后续批测继续；取消整个批测则不再开始后续。错误详情显示连接阶段、服务器及可操作建议，不显示原始密码。修改认证关键字段后旧结果变为未测试。**【v0.2】** 因服务器只支持旧算法而失败时，建议文案为“该服务器只支持 ssh-rsa，可在服务器设置中开启‘允许旧算法’”，并提供跳转。

### IXD-19 D02 信任处理

首次连接弹窗标题“确认服务器身份”，显示地址、端口、密钥算法、完整指纹和登录账号；提供“取消连接”“已核对，信任并连接”。初始焦点在取消，不默认执行信任。密钥变化时标题“服务器身份与已记录的不一致”，显示旧、新指纹并阻断，仅提供关闭和前往信任管理，不在错误弹窗放一键忽略。信任管理的更新必须再次展示差异并要求明确确认。所有指纹可选中复制，不隐藏中间关键部分。

### IXD-20 删除与环境变更

删除确认列出所有项目引用，默认动作取消，确认按钮使用“删除配置并解除绑定”；强调历史保留，不删除远端数据；**【v0.2】若该服务器有已保存凭据，列出并说明会一并删除**。环境变更显示将移除的旧环境绑定，确认后一次性提交；取消不修改环境或绑定。若活跃运行引用该服务器，连接字段、环境变更和删除都不可提交，显示关联运行入口。

## 6 发布预览与开始执行

需求对应：RUN-01–04, VAR-02–03, SEC-01–04。

### IXD-21 D03 打开顺序

点击预览或执行均先处理脏配置。纯预览可查看当前草稿且明显标注“未保存预览”；不能从未保存预览直接开始。点击执行必须选择保存并继续或取消，保存失败留在编辑页。预览只本地解析，不联网、不询问密码、不进行 sudo 探测。完整流程与仅本地命令是分段选择，切换后重新计算任务与问题。

### IXD-22 发布参数

顶部显示项目、环境、流程、执行顺序和配置版本；version 默认取解析后的 version 变量，没有则留空要求填写。完整流程列出当前环境绑定目标，可临时取消选择但不能偷偷增加未绑定目标；修改仅影响本次运行。仅本地命令隐藏目标勾选和远程授权项，并显示仅会执行的本地任务；不是远程任务失败后自动降级到本地。执行顺序在 D03 中只读显示，需要修改时返回流程设置。

### IXD-23 任务预览

按实际调度顺序展示任务序号、步骤、目标、命令或上传路径、目录、超时、失败策略及提权身份；可折叠详细命令但至少保留步骤与目标。敏感值遮蔽，普通展开值可复制。两台目标默认示例严格显示 7 项，新增第三台并绑定后显示 10 项；不能用进度条代替实际目标清单。**【v0.2】** 服务器优先时按服务器分组显示（组标题为服务器名，本地步骤和人工确认单独成行显示在组之间），步骤优先时按步骤分组；两种分组都保留全局序号。

### IXD-24 预检问题和确认

阻断问题集中列出，同时标在对应任务字段；点击问题返回原步骤并定位字段，修复后重新预览。产物尚未生成是待执行检查，不与未定义变量混为一类。保护环境要求手动键入当前环境名称；修改版本、范围或目标后清空该输入。底部固定取消与开始按钮，存在阻断问题或确认不完整时开始不可用，并有明确原因。

### IXD-25 开始与重复触发

点击开始后按钮立即进入提交中，创建唯一运行并进入 P07；网络或存储错误保留参数且给出是否已创建运行的明确反馈，未知情况下先查询已创建记录而非重复启动。同一工作区已有活跃运行时显示其入口，不能创建第二次运行。运行快照冻结，编辑页面后续变化不更新任务详情。

## 7 运行详情、任务状态与取消

需求对应：RUN-03–07, STEP-06, OBS-01–02。

### IXD-26 P07 页面组成

摘要显示项目、环境、流程、执行顺序、版本、目标数、开始时间、耗时和状态。左侧有序任务列表显示任务名称及目标（分组方式同 IXD-23）；右侧为选中任务的参数快照、退出码/传输结果和日志。日志工具栏包含任务、服务器、来源和错误筛选，搜索、跟随、导出；过滤时保留总数与已过滤标志。取消运行固定在摘要区，不随长日志滚动消失。

| 状态 | 界面反馈 | 可用操作与后续 |
|---|---|---|
| 排队 | 待执行序号；未启动不显示虚构耗时 | 可查看参数、取消整个运行。 |
| 运行中 | 当前任务高亮，显示耗时；上传显示字节与文件进度 | 可切换查看历史任务、筛选日志、取消。 |
| 等待确认 | 固定待办区显示确认提示及前序结果 | 继续或取消；切页仍保留顶部待办，不重复提交。 |
| 等待凭据 | 固定待办显示用途和服务器，不显示密码 | 打开 D04 或取消运行；后续任务不开始。 |
| 取消中 | 取消按钮禁用，显示正在停止和最后消息 | 可查看日志；不得直接显示全部已停止。 |
| 成功 | 已完成任务数、耗时、全部成功结果 | 导出、返回项目、再次执行。 |
| 失败 | 第一处失败摘要，保留其他成功/跳过结果 | 打开失败任务、导出、重新预览后执行；没有“自动回滚成功”。 |
| 已取消 | 显示取消者、时间、已执行/未执行任务 | 可查看生效操作；不会暗示远端数据已恢复。 |
| 已中断 | 明确列出结果未知的远端任务 | 提供命令与服务器信息供人工核验，不自动续跑。 |

### IXD-27 日志交互

默认跟随最新输出；用户上滚立即暂停跟随，不抢回滚动位置，出现返回最新位置的图标按钮及新增行数。任务切换保留各自阅读位置。横向长行可滚动，支持手动换行；搜索结果高亮但不改写原日志。stdout、stderr 使用来源标识，非零退出码单独显示；stderr 有输出本身不等于任务失败。已脱敏字符串不能通过复制或导出恢复。日志正文一律按纯文本渲染。

### IXD-28 人工确认

到达节点才显示确认待办，内容包括配置的提示、项目/环境/版本、实际目标列表、已完成与失败任务摘要。点击继续记录时间并仅推进一次，双击无重复任务。关闭待办详情返回运行页，运行仍等待；点击取消执行则进入整次取消流程。此处不显示“管理员已审批”等超出单操作者能力的文案。

### IXD-29 取消操作

点击取消先展示当前任务及“已完成操作不会自动撤销”的风险，按钮为“返回运行”“取消执行”。确认后立即停止后续调度；本地任务尝试终止进程树，远程任务尝试停止但未获证实时显示结果未知。关闭应用有活跃运行时提示“返回运行”或“取消并退出”，取消完成前不宣称远端已停止；操作系统强制关闭时下次启动标为已中断。

### IXD-30 失败策略的呈现

流程或步骤选择失败继续时，设置旁必须能查看其实际语义：当前任务失败后仍按顺序运行后续任务，包括同一服务器的重启。运行中失败任务保留红色文字标记但当前执行继续移动；最终汇总失败，不因后续成功变为成功。默认失败停止时，跳过任务写明“因任务 N 失败而未执行”，不是普通禁用。

**【v0.2】** 选择“跳过该服务器”时，设置旁的说明为：“某台服务器的任务失败后，该服务器剩余的任务全部跳过，其他服务器继续执行；运行最终记为失败。”运行中该服务器分组标题显示“已跳过（任务 N 失败）”，组内剩余任务写明“因任务 N 失败，跳过该服务器”；其他服务器分组正常推进。摘要区显示“N 台服务器被跳过”。

## 8 SSH 密码、私钥口令与 sudo

需求对应：SRV-02, SEC-01–04, RUN-05。

### IXD-31 D04 凭据弹窗公共行为

标题必须区分“SSH 登录密码”“解锁私钥”“sudo 授权”；显示服务器地址、登录账号及当前任务，sudo 额外显示提权目标用户，私钥显示文件路径但不显示内容。密码初始为空、默认遮蔽，显示/隐藏图标不改变输入。提交后禁用重复按钮，错误不把密码回显到消息中。

**【v0.2】** 输入框下方提供“记住此凭据（保存到 Windows 凭据管理器）”复选框，**默认不勾选**；勾选后旁边说明“可在配置中心 › 已保存凭据中清除”。使用已保存凭据自动通过时不弹窗；已保存凭据验证失败时弹窗出现，顶部提示“已保存的凭据未通过验证，请重新输入”，复选框默认勾选（输入成功后覆盖保存值）。

### IXD-32 输入、重试与取消

输入框非空后继续可用；Enter 可提交密码但不能跳过发布或信任确认。错误时显示“验证未通过，剩余 N 次”，清空输入并聚焦，最多 3 次后该任务失败。Esc 与取消按钮按当前上下文处理：发布运行中取消整个运行；连接测试中仅取消该测试。后台切页不会自动提交或将密码写入草稿。

### IXD-33 sudo 特有状态

继承策略时运行预览逐台展示实际提权方式。免交互被拒绝后显示“服务器未授予该操作的免交互权限”，不自动弹密码；用户需修改配置后重新执行。运行时密码只在服务器确实要求时弹出；授权仍受服务端策略限制，输入密码不等于一定获准。服务器要求 TTY 时显示“服务器的 sudo 配置要求终端（requiretty），当前不支持”。SFTP 上传页不出现“使用 sudo 上传”开关；上传到暂存目录与后续授权安装显示为两个独立步骤。

筛选包含项目、环境、流程、状态、时间范围；删除对象的历史仍可通过快照名称识别。列表列出开始时间、项目/流程、环境、版本、目标数、结果、耗时；点击进入只读 P07。再次执行按钮先定位原项目和流程的当前配置，展示与旧快照不同的字段，仍经过 D03。原项目或流程不存在时禁用并说明，不自动创建替代流程。

- **数据目录**：显示 `%APPDATA%\MyDeployMate` 的实际路径和“打开数据目录”按钮。
- **更新**：显示当前版本、“启动时检查更新”开关（默认开启）和“立即检查”按钮。

## 10 关键操作走查

需求对应：AC-01, AC-08–09, AC-14–15, AC-17–24, AC-27–29。

### FLOW-01 新增第三台服务器

从 P06 新建 staging-api-03，地址 192.0.2.23、端口 22、环境 staging，选择私钥并保存；新行状态未测试。用户测试并核对主机指纹后显示测试结果。进入 account-api 的 P03，此时仍选两台；勾选第三台并保存。进入 D03，构建/上传/重启/检查由 7 个任务变为 10 个；不需要修改程序代码或编译语言设置。

### FLOW-02 修改环境变量

P04 选择 staging，为 port 设置覆盖 8082，生效值与来源即时更新；保存后打开远程检查预览，当前环境解析为 8082。切到 production，仍使用其自身覆盖或项目值，不被 staging 修改。删除 staging 覆盖恢复继承；设置空字符串与删除覆盖表现不同。

### FLOW-03 未定义变量

在构建命令插入不存在的 artifact 变量并保存，点击执行；D03 显示“步骤 1 · 命令：变量 artifact 未定义”，开始禁用。点击问题返回 P02 并定位表达式；修复后重新预览。整个过程无 SSH、无构建、无上传。

### FLOW-04 两台服务器上传失败

目标 A、B；步骤优先，默认失败停止。运行顺序先构建，再上传 A，再上传 B。B 失败后 P07 显示 2 成功、1 失败、4 跳过；重启 A、重启 B、检查 A、检查 B 均未开始。摘要为失败，已上传 A 的文件保留，界面不声称已回滚。

### FLOW-05 密钥登录加 sudo 密码

用户选择 SSH 私钥、远程重启步骤的 sudo 运行时密码模式。运行到重启时若服务端要求验证，D04 显示 sudo 用途、服务器和账号，不再索取 SSH 私钥正文。用户取消后不执行待授权命令，后续任务不再启动；密码不进入日志或配置。

### FLOW-06 远程命令取消结果未知

远程构建持续执行，用户确认取消；先进入取消中。通道关闭但无法证明远端进程退出，任务显示结果未知、运行已中断，未开始任务跳过。用户能查看服务器、原命令与时间以核验；再次执行入口仍需预览且提示可能存在旧进程，不默认重放。

### FLOW-07 历史再次执行

用户选择旧发布记录，其对应流程不是项目第一个流程。点击再次执行，定位同一流程 ID 的当前版本；若命令和目标已改，展示差异后重新选择目标和确认生产环境。若原流程删除，按钮不可用且指出原因。

### FLOW-08 配置替换失败

导入 JSON 中项目引用不存在服务器：差异确认阶段之前拒绝并定位引用，当前配置保持不变。换成合法配置后先展示替换范围；取消保持原状态，确认后备份并原子替换，任何保存错误都不能显示导入成功。

### FLOW-09 服务器优先并跳过故障服务器 【v0.2 新增】

在 P02 流程设置中把执行顺序改为服务器优先、失败策略改为跳过该服务器，保存。D03 按服务器分组显示：构建；A 组（上传、重启、检查）；B 组（上传、重启、检查）。运行中上传 A 失败：A 组标题变为“已跳过（任务 2 失败）”，重启 A、检查 A 记跳过；B 组继续并全部成功。摘要为失败，显示“1 台服务器被跳过”。

### FLOW-10 记住 sudo 密码 【v0.2 新增】

运行到需要 sudo 密码的任务，D04 中输入密码并勾选“记住此凭据”，运行成功。再次运行同一流程不再弹窗。到 P10 › 已保存凭据清除该条，第三次运行重新弹窗且复选框默认不勾选。

## 11 关键错误与空状态文案

| 场景 | 建议文案 | 位置/动作 |
|---|---|---|
| 无服务器 | 当前环境没有服务器。 | P03；前往服务器管理。 |
| 没有绑定目标 | 此流程包含远程操作，请至少选择一台目标服务器。 | D03；定位目标区。 |
| 端口非法 | 端口必须是 1–65535 的整数。 | D01 端口字段下。 |
| 认证失败 | SSH 身份验证失败，请检查登录账号及认证来源。 | 测试详情；编辑服务器。 |
| 主机密钥变化 | 服务器身份与已记录的不一致，连接已停止。 | D02；查看指纹和信任管理。 |
| sudo 未授权 | 服务器未授予此命令所需的免交互权限。 | 失败任务；查看提权配置。 |
