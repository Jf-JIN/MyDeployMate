# MyDeployMate

个人服务器部署桌面工具（Tauri 2 + Rust + Vue 3 / TypeScript）。目前处于阶段 0（评审定稿与技术验证），还没有应用代码。

## 目录

- `docs/软件需求规格说明书.md`：需求规格 v0.2
- `docs/交互设计说明书.md`：交互设计 v0.2
- `docs/可行性分析与实施计划.md`：技术选型、风险评估、分阶段任务列表与已确认决策
- `docs/original/`：v0.1 原稿 PDF
- `demo/server_manager_demo.py`：原交互原型（Python 3.9+ 标准库，所有 SSH 与命令均为模拟），运行 `python demo/server_manager_demo.py`
