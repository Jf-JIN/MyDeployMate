# 设计令牌

`src/styles/tokens.css` 是按《UI 设计规范》v0.2 定义的设计令牌（2026-10-21 确认采用 v0.1 规范值，替换了最初从 Demo 提取的值），包括颜色、字体、圆角、尺寸、间距和布局宽度，用作 Vue 组件样式的唯一来源。阶段 1 起文件位于 `src/styles/tokens.css`，由 `src/main.ts` 全局引入；本目录保留设计说明，以后放组件状态展示页的截图。

几条约定：
- 组件里不写死颜色值，一律用变量。
- 状态色必须和文字或图标一起出现，不能只靠颜色区分（NFR-02）。
- 图标用 `lucide-vue-next`，描边宽度 `--icon-stroke`，尺寸 `--icon-size`。
- 变量名与 UI 规范第 2 节的语义名一一对应；改值时同步更新规范。
